# EXPERIENCE PLAYBOOK

## Rehearsal phases
1) **Cold hover**: verify MSP, MIDI port, and Rack mapping with props off (USB only).  
2) **Caged hover**: add small gestures; confirm slew/curves keep audio stable.  
3) **Musical ranges**: set attenuverters so full stick travel ≈ tasteful sweep.  
4) **Dual‑voice**: introduce channel 2; pan voices, differentiate destinations.  
5) **Show run**: lock OBS, run safety checklist, name the take in logs.

## Musical templates (starters)
- **A**: Drone A → timbre (VCF cutoff, VCO FM). Drone B → space/time (reverb wet, delay FB).  
- **B**: Both drive subtle LFO rates; macro shape comes from throttle→VCA.  
- **C**: One “leader” (roll→cutoff); second “shadow” (smaller gains, longer delays).

## OBS suggestions
- Left: FPV feed. Right: Rack window. Bottom bar: meters.  
- Use **Studio Mode** and hotkeys to toggle solo/mute of Program Audio.
